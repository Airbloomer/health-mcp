# Security

## Reporting a vulnerability

Report security issues in private. Do not open a public issue.

Use either of these:

- GitHub Security Advisories for this repository (Security, then Report a vulnerability).
- Email [security@airbloomer.com](mailto:security@airbloomer.com).

Describe what you found, the version or commit, and how to reproduce it if you can. We will acknowledge the report and coordinate a fix before any public disclosure.
